# Add your photos here

For each destination, add three JPG images: a cover image plus two gallery images.
For example, Hundred Islands uses `hundred-islands.jpg`, `hundred-islands-1.jpg`, and `hundred-islands-2.jpg`.

Cover-image filenames:

- `hundred-islands.jpg`
- `bolinao-lighthouse.jpg`
- `balungao-hot-spring.jpg`
- `patar-beach.jpg`
- `manaoag-basilica.jpg`
- `tayug-sunflower-garden.jpg`

Optional: add `logo.png` for your navigation logo.
