# Pangasinan Heritage Digital Showcase

**Project Title:** Pangasinan Heritage Digital Showcase  
**Student Name:** Denver Bryant C. Enriquez  
**Selected Framework:** React / Next.js 14  
**Live Website:** https://dezel0824.github.io/pangasinan-heritage/

## Run locally

Install dependencies with `npm install`, then use `npm run dev`. Build a deployable static site with `npm run build`; output is written to `out/`.

The project uses App Router, static local data, static export, and responsive images for GitHub Pages compatibility.
